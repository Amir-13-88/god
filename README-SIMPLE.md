# 🎉 راهنمای خیلی ساده - فقط ۲ مرحله!

## 📋 چیزایی که لازم داری:

✅ مرورگر اینترنت (Chrome, Firefox, Edge)  
✅ اتصال اینترنت (فقط برای آپلود)  
✅ ۵ دقیقه وقت  

---

## 🚀 مرحله ۱: تست برنامه (قبل از آپلود)

### ۱. فایل `Open-App.html` رو پیدا کن
- این فایل توی همون پوشه‌ای هست که این راهنما هست
- اسمش: **`Open-App.html`**

### ۲. روش دابل‌کلیک کن
- مرورگرت باز می‌شه
- برنامه لایتنر زبان اجرا می‌شه
- **تبریک! برنامه کار می‌کنه!** ✅

---

## 🌐 مرحله ۲: آپلود روی سایت (برای دیگران)

### ۱. برو به سایت Netlify
- لینک: **https://app.netlify.com/drop**
- این سایت رایگانه و نیاز به ثبت‌نام نداره (برای تست)

### ۲. پوشه `dist` رو پیدا کن
- توی همون پوشه‌ای هستی
- اسم پوشه: **`dist`**
- داخلش پر از فایل و پوشه‌های دیگه‌ست

### ۳. پوشه `dist` رو بکش و رها کن
- با موس، پوشه `dist` رو بگیر
- بکشش روی صفحه Netlify
- ولش کن (Drop)

### ۴. صبر کن
- Netlify داره آپلود می‌کنه
- ۱۰-۳۰ ثانیه صبر کن
- یه لینک بهت می‌ده، چیزی مثل:
  ```
  https://amazing-sunflower-123456.netlify.app
  ```

### ۵. تمام! 🎊
- لینک رو کپی کن
- برای دوستات بفرست
- اونا هم می‌تونن استفاده کنن!

---

## 📱 تست روی گوشی

۱. لینک رو برای خودت بفرست (تلگرام، واتساپ، ایمیل)  
۲. روی گوشیت بازش کن  
۳. برنامه باز می‌شه! ✅  

---

## 💡 اگه خواستی اسم سایت رو عوض کنی

۱. برو به: **https://app.netlify.com**  
۲. با ایمیل ثبت‌نام کن (رایگان)  
۳. سایتت رو انتخاب کن  
۴. به **Site settings** برو  
۵. **Change site name** رو بزن  
۶. یه اسم جدید بذار، مثلاً: `leitner-language`  
۷. Save بزن  

حالا لینکت می‌شه:
```
https://leitner-language.netlify.app
```

---

## 🆘 اگه به مشکل خوردی

### مشکل: فایل `Open-App.html` کار نمی‌کنه
- مطمئن شو پوشه `dist` کنارش هست
- اگه نیست، باید اول فایل‌ها رو بسازی

### مشکل: Netlify آپلود نمی‌کنه
- مطمئن شو اینترنت داری
- پوشه `dist` رو کامل بکش (نه فقط یه فایل)

### مشکل: لینک کار نمی‌کنه
- صبر کن ۱-۲ دقیقه
- دوباره امتحان کن
